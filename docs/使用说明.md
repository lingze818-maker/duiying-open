# 使用说明

## 打开

记忆库是一夹 Markdown。两种常见开法：

- 宿主能添加 MCP 时，把 [通用配置](../mcp/client.mcp.json) 里的命令、参数和授权根贴进宿主的 MCP 设置。`<插件目录>` 换成插件文件夹的路径，`<授权记忆根>` 换成笔记所在目录。这是通用稿，不针对某一个前端。
- 在终端直接问：

```bash
node <插件目录>/engine/surface.mjs "你想问的事" --root <授权记忆根>
```

配好之后新开一轮对话。可以在系统提示里约定：每轮先按用户的话检索记忆，命中的线索自然引用，对方没问就不要逐条罗列。

## 怎么问

用平时说话的方式问过去的决定、约定或事件。几件事可以写成 `部署,回滚`，用逗号分开。只问「最近」、没有别的话题时，会按笔记上的日期列出较新的几篇。

## 怎么读引用

每一条大致是：

```text
- [日期] 标题 —— 相对路径
  关联: 另一篇.md
  此条已被取代，见 另一篇.md
```

日期是这件事记下来的日子。路径是授权根里面的文件，打开它就是原文。关联是引擎觉得相近的篇目。出现「已被取代」时，以它指向的那篇为准，旧篇仍留在磁盘上。

没有对上的笔记时，结果是空的，并说明没有命中。可以换更具体的说法，或确认授权根指对了。

## 让一篇不再被提起

在该文件最上面写：

```markdown
---
suppress: true
---
```

整篇都不再浮出，文件原样留着。只在某些话题下沉默时：

```markdown
---
suppress_when: [关键词A, 关键词B]
---
```

查询里含这些词时，这一篇不浮。拿掉这几行，它会重新参与检索。

试用前可以对虚构示例跑一句：

```bash
node engine/surface.mjs "部署" --root examples/partner-xiaolin
```

结果里应能看到会议纪要和决策记录的路径。示例不是真实材料。
