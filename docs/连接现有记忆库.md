# 连接你的现有 Markdown 文件

> 引擎不需要任何格式转换——**任何装着 `.md` 文件的文件夹，就是一个记忆库**。
> 把 `--root` 指过去，立刻可以检索。

---

## 最短路径

```bash
node engine/surface.mjs "最近的工作计划" --root /path/to/你的笔记文件夹
```

就这一步。引擎会**递归扫描**该目录下所有 `.md` 文件并建立索引。

## 常见来源对照

| 你的笔记在哪 | 做法 |
|---|---|
| Obsidian vault | `--root /path/to/vault`（整个 vault 或某个子目录皆可） |
| Logseq journals | `--root /path/to/logseq/journals` |
| zcode / Claude Code 的 auto-memory 目录 | `--root ~/.xxx/memory`（指向 memory 目录本身） |
| 随手写的笔记文件夹 | `--root /path/to/notes` |
| 分散在多个目录 | `--root 目录A --root 目录B --root 目录C`（可重复） |

## 引擎读什么、忽略什么

**读**：所有 `.md` 文件（递归），UTF-8。

**自动跳过**的目录：`node_modules`、`.git`、`build`、`dist`、`asar`、
`vendor` 等——依赖和构建产物不会污染检索。

**文件内的约定**（全部可选，没有也完全能用）：

- 首行 `# 标题` → 成为检索结果的路标名称
- frontmatter（`---` 包裹的键值对）→ 可选的状态控制：

```markdown
---
superseded_by: 新文件.md     # 此条已被取代：降权保留，附注指向新文件
suppress: true               # 整篇不浮出（文件原样保留）
suppress_when: [关键词]      # 仅当查询命中关键词时不浮出
---
```

**不做任何修改**：引擎对文件只读。检索、降噪、去重全部发生在结果层，
你的原文件一个字都不会变。

## 接入 AI 前端

让 agent 用上你的记忆（三选一，详见[接入契约](接入契约.md)）：

**MCP（推荐）**——宿主配置里指向引擎并声明语料根：

```json
{
  "duiying-memory": {
    "command": "node",
    "args": ["/path/to/duiying-open/mcp/server.mjs"],
    "env": { "DUIYING_ROOTS": "/path/to/笔记A;/path/to/笔记B" }
  }
}
```

**CLI**——工具定义里包一层：

```bash
node engine/surface.mjs "$QUERY" --root /path/to/笔记 --json
```

**Node 内嵌**——`import { search } from "duiying-open/engine/core.mjs"`。

## 常见问题

**中文笔记可以吗？**
可以。中文按字符 bigram 建索引，不需要分词器，也不需要语言设置。

**多少文件合适？**
为个人记忆库设计（数十到数千篇）。千篇级毫秒到秒级出结果。

**txt / 其他格式呢？**
当前只索引 `.md`。纯文本可以先改名 `.md`（引擎只按内容检索，
不强制 Markdown 语法），或等待后续版本的格式扩展。

**会不会把我的笔记改坏 / 传到网上？**
不会。引擎对文件只读、无网络行为、无遥测——详见 [SECURITY.md](../SECURITY.md)。
`doctor` 体检也只输出报告，不改文件。
