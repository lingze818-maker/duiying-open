# 企业记忆库 · 安装手册

_适用版本：v0.5-enterprise-preview（2026-11-22）· 面向单位内网管理员 · 全程不需要外网_

---

## 一、这个系统是什么

单位内部的**记忆/知识检索库**：把会议纪要、项目档案、制度文件等放进来，
按权限分库，全员检索。**数据完全留在单位内网机器上，运行过程不访问任何外部服务。**

## 二、环境要求

| 项目 | 要求 | 不满足时 |
|---|---|---|
| 操作系统 | Windows 10+ / 国产 Linux（麒麟、UOS 实测计划内） | 其他 Linux 亦可运行 |
| Node.js | ≥ 22（离线安装包见附录一） | 未安装则服务无法启动 |
| 磁盘 | ≥ 1GB（纯词面模式）/ ≥ 2GB（启用向量检索） | — |
| 内存 | ≥ 2GB | — |
| 网络 | **完全离线可用** | 无任何外呼 |

## 三、快速安装（Windows，内网机器）

1. 把 `duiying-open` 整个目录拷贝到目标机器（U 盘/内网共享均可）；
2. 双击 `deploy\install.bat`；
3. 看到「地址：http://127.0.0.1:<端口>」即启动成功（默认端口 8766，可改）——同网段任何电脑的浏览器打开「http://<部署机IP>:<端口>」即可检索。

**分库配置**：编辑 `workspace\workspace.json`（JSON 格式）：
```json
{
  "libs": {
    "common":  { "path": "./memories/common",  "readers": ["*"], "writers": ["admin"] },
    "finance": { "path": "./memories/finance", "readers": ["group:finance"], "writers": ["group:finance-lead"] }
  },
  "users": {
    "zhang": { "groups": ["finance"], "libs": ["common", "finance"] }
  }
}
```
- `readers`/`writers` 支持 `"*"`（所有人）、具体工号/姓名、`"group:组名"`；
- **权限在检索之前生效**：未授权的库根本不会出现在用户的检索范围内；
- 改完配置重启服务（Ctrl+C 后重跑 install.bat）。

## 四、导入存量文档

把单位的 Word/Excel/Markdown/文本文件放进一个目录，然后：

```bat
node scripts\import-docs.mjs --root workspace\memories\common --src D:\单位文档目录
```

- 长文档自动按标题/段落切块；每块记录来源与时间；
- Word（.docx）与 Excel（.xlsx）支持需要可选依赖（见第三章），未安装时这些文件被跳过并记录原因，不影响其他文档。

## 五、启用向量检索（可选，语义检索）

词面检索只能按字面关键词命中。启用向量路后，**意思相近但用词不同**的内容也能被找到
（搜「服务器宕机」能命中写着「服务中断」的纪要）。

1. 离线包 `vendor\offline-deps` 放入可选依赖与模型文件（BGE 中文小杯，约 90MB，随安装介质分发）；
2. 重跑 install.bat，脚本检测到离线包会自动安装；
3. 启动时设置 `ENTERPRISE_VEC=workspace\vectors`；
4. 首次导入文档后运行 `node scripts\build-vector-index.mjs` 生成向量索引。

**不启用向量检索，系统所有其他功能照常可用。**

## 六、审计日志

所有检索自动记录：`workspace\audit\audit.jsonl`（一行一条：时间、使用者、检索词、可见库）。
**审计只记检索行为，不记录命中内容**——审计是安全工具，不是监视工具。

## 七、常见问题

- **端口被占用**：改启动前 `set PORT=8767`；
- **检索不到预期内容**：①确认使用者账号在 workspace.json 的 users 里且 libs 列了目标库；②确认文档已导入成功（importer 输出 imported 数）；③确认该文档内容里确实包含相关用词（未启用向量时是字面匹配）；
- **想重置所有数据**：删除 workspace\memories 下的文件即可（**删前备份**，系统不做二次确认）；
- **服务开机自启**：把 install.bat 的快捷方式放进「启动」文件夹，或用任务计划程序注册。

## 附录一 · Node.js 离线安装

官网下载 Windows 安装包（.msi）拷贝到目标机双击安装；国产 Linux 下载对应架构 tar.xz 解压并把 bin 目录加入 PATH。

## 附录二 · 信创适配说明

引擎为纯 JavaScript 实现（无原生编译模块必需），理论上跨架构可用；向量检索依赖的 ONNX 推理在国产 CPU（鲲鹏/飞腾）上的实测列在路线图中（M3 里程碑），实测结果将更新在本节。

## 附录三 · 数据安全声明

- 本系统全部数据（记忆文件、索引、审计日志）存储于单位内网机器本地磁盘；
- 运行时代码不包含任何外联地址，不产生任何出网流量（可由防火墙日志复核）；
- 卸载 = 删除目录，数据随文件一起移除，无云端残留。
