它凭什么不同

记忆是检索问题，不是存储问题——路标式注入，一行一条线索。

BM25 + 专名短语融合中文按字符 bigram 无需分词器；关键词整串命中单独计强分
时间先验最近的记忆自然更容易想起；查询含"最近/上周/去年"自动切时间优先模式
联想上浮（浮一带二）记忆自动互链，命中一条带出相关几条——"提到部署，想起三月的选型决策"
取代而非删除事实变了？旧条目标 superseded_by 降权保留，上浮时自带"已被取代"附注
沉默列表suppress / suppress_when——有些记忆不该被提起，但浮不上来 ≠ 删掉
路标式注入一行一条线索不灌全文——同样 token 预算能容纳更多条记忆
不背档案结果自带"除非对方问起，不要主动罗列"的措辞——记忆应在言谈中自然流露
doctor 体检 + 自动降噪检索时自动应用安全修正（近重复只浮最新、坏链附注静默降级）；--doctor 报告供深度清理参考

doctor 体检

坏链 / 近重复 / 标题质量 / 沉默清单——检索时自动降噪，报告只报不修。

node engine/surface.mjs --doctor --root ./我的记忆库
