# 边界说明

对影这一版跑在你自己的机器上。检索、体检，以及把一个目录里的 Markdown 收进授权根，都只读写本机路径。没有账号，没有上传，没有遥测。

## 读什么

只读配置里写明的授权目录（`DUIYING_ROOTS`，或单次调用里的 `root`）。授权目录以外的文件不会被扫进来。同步也只把结果写进你指定的那一个授权根，并且不改、不删源目录里的文件。

## 它做什么

上浮给出的是线索：日期、标题、文件路径，有时还有一行摘录。它帮你想起可能相关的笔记。要不要引用、信哪一条，由人和对话里的模型决定。引擎不改笔记原文。

沉默（`suppress` / `suppress_when`）只是检索时不浮出，文件还在。取代（`superseded_by`）是降权并附注，文件也还在。

## 规模

公开说明里的范围是数十到数千篇笔记，默认每次查询全量扫描。再大时，可以在每个授权根下建一份可选的词法候选索引（`.duiying/`）。没有这份索引、索引损坏，或没装那个可选包时，结果与全量扫描相同。

词法召回是单独的一层，以后可以换掉这一层的实现，排序仍在原来的引擎里。向量候选源这一版是空的：没有编码器，没有向量文件，排序也不使用向量。

源文件到 Markdown 的转换同样是空位。收进授权根的，只有源目录里已经是 Markdown 的文件，或事先改好后缀的 `.md`。这一版不转换 Word、PDF 或 WPS。

## 发现错了

1. 按引用里的路径打开原文，核对是不是那一篇。
2. 不该被提起的篇目，在文首加上沉默标记。事实已经变了，就改文件，或写上取代指向。
3. 若是引擎该浮没浮、不该浮却浮了，到公开仓库开一条 issue。不要把笔记原文贴出去，也不要把别人机器上的文件拷走。
