# 对影 · 人机搭档记忆库（开源版）

> **让普通人与 AI 的长期协作，长出"它真的记得我"的体感。**
>
> 纯本地 · 零依赖 · 一个 Node 脚本就是全部。

对影的记忆上浮引擎：扫描你的 Markdown 记忆库，把"可能相关的记忆"
以**路标**（一行一条）浮上来，交给任意 AI 前端（zcode / codex /
deepseek harness / 你自建的前端）注入对话——**只浮线索，不替记忆**。

## 它解决什么

大多数人和 AI 的关系不是"恋人"，是**搭档**：一起做项目、记决策、
续上下文。而几乎所有 AI 前端都患同一种健忘——上周拍过的板，这周
重新吵一遍。对影把"记忆"做成检索问题而非存储问题：

- **BM25 + 专名短语**两路融合打分（中文按字符 bigram，无需分词器）
- **时间先验**：最近的记忆自然更容易想起；问"最近…"自动切时间模式
- **联想上浮**：记忆自动互链，命中一条带出相关几条——"提到部署，
  想起三月的选型决策"
- **路标式注入**：一行一条线索，token 预算内装下三倍记忆量
- **不背档案**：结果自带"除非对方问起，不要主动罗列"的措辞建议

**没有向量数据库，没有图数据库，没有本地小模型，没有 API key。**
一个 `surface.mjs`，Node 18 以上就能跑。

## 快速开始

```bash
git clone https://github.com/lingze818-maker/duiying-open.git
cd duiying-open
node engine/surface.mjs "部署,回滚" --root examples/partner-xiaolin --detail
```

给程序消费（任意前端接入点）：

```bash
node engine/surface.mjs "部署" --root ./我的记忆库 --json
```

```json
{
  "engine": "duiying-open/0.2",
  "query": ["部署"],
  "hint": "除非对方问起或自然相关，不要主动罗列这些记忆。",
  "results": [
    { "path": "决策记录.md", "title": "项目决策记录", "date": "2026-04-01", "score": 12.3, "links": ["会议纪要.md"] }
  ]
}
```

把 `results` 以 system prompt 附加线索的形式喂给你的 AI，
记忆就有了。

## 哲学

**只浮线索，不替记忆。**

检索结果不改写、不删除、不裁决任何记忆。2025-2026 年行业头部
记忆系统（Mem0 v3、Graphiti）不约而同收敛到同一条原则：
*记忆原文神圣，智能放在检索层*。对影从第一天就长在这里。
